# Market Research Dashboard Templates

A collection of `DESIGN.md` templates for **market research dashboards**, inspired by
[awesome-design-md](https://github.com/VoltAgent/awesome-design-md).

awesome-design-md captures the design systems of websites. This repo does the same for
MR dashboards, and adds sections on data visualization, page structure and chart specs
for each study type (BHC, U&A, HUT, Ad Test, and more).

## How to use

1. Copy a template folder (e.g. `design-md/bhc/bhc-01/`) into your project.
2. Give its `DESIGN.md` to your AI coding agent and ask it to build the dashboard following it.
3. Open `preview.html` / `preview-dark.html` to see the look.

Each template folder contains:

- `DESIGN.md`: the design system the agent reads
- `preview.html`: visual preview (light)
- `preview-dark.html`: visual preview (dark)

## What's inside each DESIGN.md

Sections 1–8 and 13 follow awesome-design-md. Sections 9–12 are specific to MR dashboards.

| # | Section | Captures |
|---|---|---|
| 1 | Visual Theme & Atmosphere | Mood, density and design philosophy of the dashboard. |
| 2 | Color Palette & Roles | Semantic color names, hex values and their functional roles. |
| 3 | Typography Rules | Font families and the full type hierarchy. |
| 4 | Component Stylings | Buttons, cards, filters, KPI tiles, tables and their states. |
| 5 | Layout Principles | Grid, spacing scale and whitespace rules. |
| 6 | Depth & Elevation | Shadow system and surface hierarchy. |
| 7 | Do's and Don'ts | Design guardrails and anti-patterns. |
| 8 | Responsive Behavior | Breakpoints, touch targets and collapsing strategy. |
| 9 | Data Visualization Rules | Rules for data viz: chart choice, color encoding, significance marking, base sizes. |
| 10 | Dashboard Structure | List of dashboard pages and navigation. |
| 11 | Page Layouts | Where each chart sits on each page. |
| 12 | Chart Specifications | Detailed design of each chart (type, measures, labels, interactions). |
| 13 | Agent Prompt Guide | Ready-to-use prompts for AI agents building with this template. |
